# Handwritten Digit Recognition using CNN

## Project Overview
This project is a Handwritten Digit Recognition application developed using Python and Convolutional Neural Networks (CNN). It uses the MNIST dataset to recognize handwritten digits (0–9) and provides an interactive interface where users can draw digits and get real-time predictions.

## Features
- Recognizes handwritten digits from 0 to 9.
- Uses a trained CNN model for digit classification.
- Interactive drawing interface using Tkinter.
- Displays the predicted digit based on the user's drawing.
- Achieved approximately 97.63% test accuracy.

## Technologies Used
- Python
- Convolutional Neural Networks (CNN)
- TensorFlow / Keras
- MNIST Dataset
- Tkinter
- NumPy

## Project Files
- `drawing_app.py` – Interactive application for drawing handwritten digits.
- `predict.py` – Handles digit prediction using the trained model.
- `digit_model.h5` – Trained CNN model.
- `digit.png` – Sample digit image.

## Model Performance
- Dataset: MNIST
- Test Accuracy: 97.63%

## How to Run

1. Clone this repository:
   `git clone https://github.com/Brindhasellakannu/Handwritten-Digit-Recognition.git`

2. Install the required libraries:
   `pip install tensorflow numpy pillow`

3. Run the application:
   `python drawing_app.py`
